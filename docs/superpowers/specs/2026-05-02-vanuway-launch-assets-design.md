# VanuWay Launch Assets Design

## Approved Direction

The approved campaign direction is **Connected Islands, refined**.

The campaign should feel like a polished national launch: trustworthy, energetic, modern, and clearly built for Vanuatu. The visual system uses VanuWay navy as the base, launch orange for action and momentum, black for premium contrast, and white space for readability around app screenshots and service lists.

## Campaign Message

Primary line:

**One app for everyday Vanuatu.**

Supporting line:

Book rides, order food, find hotels and tours, shop local, list property, get alerts, learn Bislama, find jobs and more.

Tone:

- Confident and practical
- Proudly local
- Clear enough for first-time users
- Premium enough for partners, vendors, hotels, tour operators, and advertisers

## Services To Include

All launch assets must represent the full VanuWay ecosystem:

- Ride-hailing
- Package delivery
- Food delivery
- Shop delivery
- Marketplace
- Hotels and accommodation
- Tours and attractions
- Ferry and flights
- Learn Bislama
- Emergency alerts
- Community events
- Service providers
- Real estate
- VanuHealth
- VanuJobs
- Partner and vendor dashboards

The service list can be grouped visually to avoid feeling like a long checklist:

- Move and deliver
- Eat and shop
- Travel and stay
- Community and safety
- Property, health, and work
- Grow your business

## Video Package

Create one complete flagship launch video plus cutdowns.

Flagship launch video:

- Target length: 90-120 seconds, longer if needed to show every service clearly
- Format: landscape first, suitable for Facebook and YouTube
- Content source: real recordings from `https://vanuway.com` and `https://app.vanuway.com`
- Structure:
  1. Brand opener: VanuWay logo, launch line, Vanuatu-wide promise
  2. Everyday user flow: rides, delivery, food, shopping, marketplace
  3. Travel flow: hotels, tours, ferry, flights
  4. Community flow: Bislama, events, emergency alerts, service providers
  5. Growth flow: real estate, VanuHealth, VanuJobs, vendor dashboards
  6. Proof montage: real screenshots and dashboard recordings
  7. Closing CTA: Visit vanuway.com or open app.vanuway.com

Cutdowns:

- 60s landscape for Facebook and YouTube ads
- 60s vertical Reel/Shorts for Instagram, Facebook Reels, and YouTube Shorts
- 15s paid social cutdown
- 6s bumper

## Static Assets

Create a launch set with consistent styling:

- A4 launch flyer
- Square feed ad
- Vertical story/Reel cover
- Vendor recruitment flyer
- Service overview graphic
- Phone mockups using real screenshots from the app

Static layouts should use the refined Connected Islands palette:

- Navy `#233C6F` as the primary background
- Orange `#EF5E33` for CTA bands, labels, and highlights
- Black `#000000` for premium contrast and closing frames
- White `#FFFFFF` for space, text clarity, and screenshot framing

## Ad Scripts And Copy

Prepare scripts and captions for:

- Facebook launch post
- Instagram launch post
- YouTube video description
- 15s paid ad script
- 60s narration script
- Longer flagship narration script
- Vendor recruitment ad copy

The scripts should mention all services without becoming crowded. The best pattern is to name key services individually, then group the rest in fast montage lines.

## Recording Requirements

Record public website sections from:

- `https://vanuway.com`
- Services page
- Business/partner sections if available

Record app/dashboard sections from:

- `https://app.vanuway.com`
- Home/service grid
- Ride or ride hub
- Marketplace
- Hotels
- Tours
- Ferry/flights
- Food/shop if visible
- Messages or notifications
- Partner/vendor/admin dashboard screens

A temporary test account is needed for real dashboard recordings. Best access is either admin or a seeded demo account with user, vendor, and dashboard visibility. Credentials should be temporary and changed after production.

## Deliverables

The production pass should output:

- Rendered flagship landscape video
- Rendered 60s landscape video
- Rendered 60s vertical Reel/Shorts video
- Rendered 15s paid social video
- Rendered 6s bumper
- Exported flyer and social graphics
- Screenshot/mockup image set
- Written ad scripts and captions
- Notes on any pages that could not be captured because of login or missing demo data

## Open Dependency

Real dashboard footage depends on receiving a temporary test login. Public website footage can be captured without it.
